# FitLog 🏋️

FitLog is a simple fitness and workout tracking web application built with **Next.js**. It helps users explore workouts, create a workout plan, save exercises, and track their daily workout statistics.

## ✨ Features

* 🏋️ Browse different workouts
* ➕ Add workouts to today's plan
* 💾 Save favorite workouts
* 📊 Track daily exercises, minutes, and calories
* 🔄 Sort workouts by duration, calories, or rating
* 📱 Responsive design for desktop and mobile
* ⚡ Fast and modern UI

## 🛠️ Technologies

* Next.js
* React
* TypeScript
* Tailwind CSS
* React Context API
* DaisyUI

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/sayeemahmed12/FitLogWithNextJS.git
```

Go to the project directory:

```bash
cd FitLogWithNextJS
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
